# 정리 후보 살펴보기와 앱 복원

정리 후보는 **먼저 확인해 볼 만한 항목**입니다. 삭제해도 된다는 판정은 아니므로, 내용을 확인하고 계속 쓸 것인지 직접 결정해 주세요.

## 어떤 항목이 후보로 나오나요?

| 종류 | 표시 기준 | 정리 전 확인할 점 |
|---|---|---|
| 설치 파일 | Downloads 안의 dmg·pkg·mpkg·iso, 20 MB 이상 | 설치를 마쳤는지, 다시 받을 수 있는지, 안에 개인 자료가 있는지 |
| 오래된 다운로드 | Downloads 안의 파일, 마지막 수정 후 90일 이상, 20 MB 이상 | 수정일은 마지막 사용일과 다릅니다. 필요한 원본 문서인지 확인하세요. |
| 압축 파일 | Downloads 안의 zip·7z·rar·tar·gz·xz, 100 MB 이상 | 압축을 풀었는지, 별도 원본이 있는지 |
| 빌드 데이터 | 사용자 Xcode의 DerivedData, 20 MB 이상 | 다시 빌드하거나 검색용 정보를 만드는 데 시간이 들 수 있습니다. |
| 앱 캐시 | 사용자 Library/Caches 바로 아래 항목, 20 MB 이상 | 해당 앱의 관리 기능을 먼저 확인하세요. 데이터를 다시 받아야 할 수 있습니다. |
| 큰 앱 | .app 묶음, 100 MB 이상 | 계속 쓰는 앱인지, 앱 안에 중요한 자료가 있는지 |

측정한 디스크 점유량이 큰 순서로 보여줍니다. 상위 폴더가 후보이면 그 안의 항목을 중복 후보로 표시하지 않습니다. 앱·보관함 내부, 알려진 클라우드 동기화 위치, 시스템 관리 경로, 하드 링크, 점유량이 없는 항목은 후보에서 제외합니다. 일부만 읽은 항목에는 ‘일부’를 표시합니다.

**이번 실행에서는 보관**을 누르면 후보 목록에서 숨길 수 있습니다. 파일을 옮기거나 지우는 기능은 아닙니다. 보관 항목 표시를 켜면 다시 볼 수 있습니다.

## 분석 범위가 달라질 수 있어요

**후보 위치 분석**은 다운로드·응용 프로그램·사용자 캐시·Xcode 빌드 데이터를 분석합니다. 새 분석을 시작하면 이전 결과를 교체하고, 완료하거나 중지했을 때 확인한 범위에서 후보를 분류합니다.

**앱 관리 → 목록의 앱 크기 분석**도 현재 저장 공간 분석 결과를 교체합니다. 다른 화면에 돌아왔을 때는 상단의 분석 범위를 확인해 주세요.

## 용도 설명은 어떻게 제공하나요?

알려진 폴더와 일부 앱은 위치나 앱 식별자를 바탕으로 용도와 공식 도움말을 안내합니다. 예를 들어 Xcode·Chrome·Visual Studio Code·Docker Desktop의 알려진 식별자를 참고합니다. 이름이나 식별자가 같다는 이유만으로 앱의 진위나 데이터 소유를 보장하지는 않습니다.

설명을 확인하기 위해 자동으로 웹에 접속하지 않습니다. 공식 도움말이나 용도 검색 링크를 직접 누르면 브라우저가 열립니다. 검색어는 화면에서 확인할 수 있으며, 개인 파일명이나 전체 경로는 검색어로 보내지 않습니다.

## 앱을 휴지통으로 옮기기

일반 파일과 관련 Library 데이터는 조회만 합니다. 앱 안에서 옮길 수 있는 대상은 `/Applications` 또는 `~/Applications` 아래 허용된 위치의 **앱 본체 하나**입니다.

1. 앱 관리에서 대상 앱을 선택하고 용도·위치·크기를 확인합니다.
2. 앱 본체 선택란을 직접 켭니다. 처음에는 선택되어 있지 않습니다.
3. **선택 항목 검토**를 누르고 전체 경로를 확인합니다.
4. 안내된 `.app` 파일명을 정확히 입력한 뒤 이동합니다.

다른 앱으로 바꾸거나 검토를 취소하면 선택이 해제됩니다. 검색·사용 기록 조건을 바꿀 때도 선택을 해제합니다. 실행 중인 앱과 바뀐 파일을 다시 확인하며, 관련 Library 데이터는 함께 옮기지 않습니다. 앱 본체 안에도 중요한 자료가 있을 수 있으므로 내용을 먼저 확인하세요.

## 옮긴 앱 복원하기

이동된 항목을 확인할 수 있으면 **이번 실행에서 휴지통으로 옮긴 항목**에 복원 버튼을 표시합니다. 원래 위치에 다른 파일이 있으면 덮어쓰지 않습니다.

파일이나 상위 폴더가 바뀌었거나 휴지통이 비워졌다면 복원할 수 없습니다. 앱을 종료하면 앱 내 복원 목록은 사라지므로, 이후에는 Finder의 휴지통에서 확인하세요. 휴지통은 언커뮤가 자동으로 비우지 않습니다.

파일 확인과 실제 이동이 동시에 보장되는 작업은 아니므로, 검사 직후 다른 프로그램이 파일을 변경하는 경우까지 완전히 막지는 못합니다.

## 분석이 오래 걸리거나 일부만 나올 때

스캔은 최대 250,000개 항목 등 한도를 두고 진행합니다. 폴더 목록의 응답이 5초 이상 지연되면 해당 위치를 건너뛰고 미확인 상태를 표시합니다. 이 시간 제한이 모든 파일 정보 조회에 적용되는 것은 아닙니다.

분석을 중지하면 그때까지 확인한 결과를 볼 수 있습니다. 필요한 폴더만 직접 선택해 다시 분석해 보세요. 클라우드·외장·네트워크 위치의 동작은 추가 검증이 필요합니다.
