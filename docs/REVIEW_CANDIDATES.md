# 정리 후보와 복원 — 2026-09-27

## 후보 조건

후보는 삭제 추천이나 안전성 인증이 아니다. 스캔의 디스크 점유량을 사용하고 자동 삭제나 확보 가능량 합산은 하지 않는다.

| 종류 | 조건 | 확인할 점 |
|---|---|---|
| 설치 파일 | Downloads 안의 dmg/pkg/mpkg/iso, 20 MB 이상 | 설치 완료·재다운로드 가능 여부와 이미지 안의 개인 자료 |
| 오래된 다운로드 | Downloads 안의 파일, 마지막 수정 90일 이상, 20 MB 이상 | 수정일은 마지막 사용일이 아니며 원본 문서일 수 있음 |
| 압축 파일 | Downloads 안의 zip/7z/rar/tar/gz/xz, 100 MB 이상 | 압축 해제 여부와 별도 원본 |
| 빌드 데이터 | 사용자 Xcode DerivedData 경로, 20 MB 이상 | 다시 빌드·인덱싱하는 비용 |
| 앱 캐시 | 사용자 Library/Caches 바로 아래 항목, 20 MB 이상 | 소유 앱의 관리 기능과 재생성·재다운로드 |
| 큰 앱 | .app 패키지, 100 MB 이상 | 사용 여부와 관련 데이터는 별도 검토 |

순서는 측정된 크기순이다. 한 항목은 하나의 분류에만 들어가며 상위 후보가 있으면 하위 후보는 중복 표시하지 않는다. 앱/보관함 내부, 알려진 클라우드 동기화 위치, 시스템 관리 경로, 하드 링크와 점유량이 없는 항목은 제외한다. 부분 측정은 '일부'로 표시한다. '이번 실행에서는 보관'은 목록 필터일 뿐 파일을 바꾸지 않는다.

후보 위치 분석은 다운로드, 시스템/사용자 Applications, 사용자 Caches, Xcode DerivedData를 읽는다. 이전 탐색 결과를 새 스캔으로 교체하며 완료/중지 시 후보를 분류한다. 앱 목록의 크기 분석도 같은 결과 모델을 사용한다. 이름순과 크기순을 선택할 수 있고 미측정은 아래에, 부분 크기는 일부로 표시한다.

## 용도 설명

Xcode, Chrome, Visual Studio Code, Docker Desktop의 정확한 Bundle ID에 공식 페이지 기반 설명을 제공한다. 로컬 식별자는 앱 진위나 독점 데이터 소유를 보증하지 않는다. 연결 페이지 외 자동 웹 전송은 없다. 출처는 앱의 설명에 표시한다.

- https://developer.apple.com/xcode/
- https://www.google.com/chrome/
- https://code.visualstudio.com/
- https://docs.docker.com/desktop/uninstall/

## 이동과 복원

2026-10-01 안전성 강화: 관련 Library 경로는 조회 전용이며 선택·이동할 수 없다. Bundle ID와 경로 이름이 같아도 문서·설정 등 중요한 데이터가 있을 수 있기 때문이다. 앱 안에서는 `/Applications` 또는 사용자 `~/Applications` 아래 제한된 깊이의 `.app` 본체 하나만 휴지통으로 이동할 수 있다. 앱 선택은 기본 해제되고, 검토 화면의 정확한 전체 경로를 확인한 뒤 `.app` 파일명을 다시 입력해야 이동 버튼이 열린다. 다른 앱으로 바꾸거나 검토를 취소하면 선택을 해제한다.

이동된 실제 경로와 identity를 확인할 수 있으면 현재 실행 동안 복원 버튼을 제공한다. 원래 상위 폴더와 이동된 항목의 identity를 다시 확인하며 같은 위치의 다른 파일은 덮어쓰지 않는다. 파일이나 상위 폴더가 바뀌었거나 휴지통이 비워졌다면 복원을 거부한다. 앱을 종료하면 메모리의 복원 목록은 사라지고 Finder 휴지통에서 확인해야 한다. 검사와 OS 이동은 원자적이지 않으므로 외부 변경의 경쟁 조건은 남는다. `.app` 내부에도 중요한 데이터가 있을 수 있으므로 앱 본체의 불필요 여부는 사용자가 확인해야 한다.

## 스캔 응답성

250,000개 전체 한도를 여러 루트에 배분해 앞의 큰 루트가 나머지를 소진하지 않도록 했다. 폴더 열기가 지연되면 5초 뒤 해당 위치를 미측정 처리한다. OS 호출 자체를 강제 중단하지는 못하므로 응답을 기다리는 읽기를 최대 4개로 제한하고 늦은 결과는 버린다. 이 제한에 도달한 위치도 미측정으로 남긴다. 중지는 대기 중에도 확인한다. lstat, 패키지 메타데이터 등 모든 파일 시스템 호출에 대한 강제 시간 제한은 아니며 네트워크/파일 제공자별 추가 검증이 필요하다.
