# 변경 이력

## 후보 판단 개선 — 2026-11-16 (main)

- 후보를 확인 우선순위와 크기로 정렬하고, 종류별 확인 질문을 추가했습니다.
- 계속 보관·나중에 검토·정리 검토 판단을 이 Mac에 저장합니다.
- 파일 식별 정보·크기·수정 정보가 달라지면 다시 판단하도록 표시합니다. 질문 확인이나 판단 기록은 삭제를 실행하거나 승인하지 않습니다.

## 설치 위치 변경 — 2026-11-16 (main)

- 기본 설치·업데이트·복구 위치를 공용 응용 프로그램 폴더인 `/Applications`로 변경했습니다.
- 설치 계정에 쓰기 권한이 없으면 빌드 전에 안내합니다.

## 파일 정리와 새 아이콘 — 2026-11-16 (main)

- 빌드·실행·복구·검사 스크립트를 `scripts/`로 모았습니다. 설치는 그대로 `bash setup.sh`입니다.
- 기여 안내를 `.github/`로 옮기고 README에 소스 구조를 정리했습니다.
- 폴더 속 공간을 살펴보는 고양이 아이콘을 앱 번들과 README에 적용했습니다.
- 설치 검사에 사용하는 임시 실행 파일을 다시 서명해 macOS가 실행을 거부하는 문제를 수정했습니다.
- 기존 v0.2.0-alpha.1 태그는 유지합니다. 이 변경은 main 소스에 들어 있습니다.

## 테스트 수정 — 2026-11-16

- 분석 중단 테스트가 30ms 안에 취소해야 통과하던 문제를 고쳤습니다. 첫 결과 이후의 대기 지점을 직접 제어하도록 바꿨습니다.
- 중단 시 부분 결과 보존, 최종 결과 미반영, 재시도, 완료 후 취소를 확인합니다. 사용자 여정 검사는 67개입니다.
- 로컬 반복 실행과 GitHub의 전체 205개 검사, 앱 빌드·서명 검증을 통과했습니다.
- 앱 기능과 공개 태그는 변경하지 않았습니다.

## 문서 업데이트 — 2026-11-15

- 소개와 설치 안내를 다듬고, 반복되는 설명과 어려운 표현을 줄였습니다.
- 문의와 버그 제보는 텔레그램으로 안내합니다.
- GitHub의 사용자 여정 테스트 실패 내용을 문서에 남겼습니다.
- 앱 기능과 버전, 이미 공개된 태그의 소스는 변경하지 않았습니다.

## v0.2.0-alpha.1 — 첫 공개 테스트 버전

- 폴더 트리·큰 폴더·큰 파일을 같은 분석 결과에서 탐색합니다.
- 파일 종류·최소 크기·이름으로 검색하고 폴더 내부로 좁힐 수 있습니다.
- 정리 후보에 근거와 확인할 점을 표시하고 Finder로 연결합니다.
- 앱의 크기·마지막 사용 기록을 참고하고 보관할 앱을 표시합니다.
- 앱 본체 하나만 별도 확인 후 휴지통으로 이동합니다. 관련 Library 파일은 조회만 합니다.
- 직접 빌드·설치·이전 버전 복구 스크립트를 제공합니다.

앱 내부 버전은 0.2.0 (2)입니다. 검증 범위와 남은 과제는 [테스트 안내](TESTING.md)를 참고하세요.
