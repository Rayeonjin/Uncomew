# 변경 이력

## 테스트 수정 — 2026-11-16

- 분석 중단 테스트가 30ms 안에 취소해야 통과하던 문제를 고쳤습니다. 첫 결과 이후의 대기 지점을 직접 제어하도록 바꿨습니다.
- 중단 시 부분 결과 보존, 최종 결과 미반영, 재시도, 완료 후 취소를 확인합니다. 사용자 여정 검사는 67개입니다.
- 앱 기능과 공개 태그는 변경하지 않았습니다.

## 문서 업데이트 — 2026-11-15

- 소개와 설치 안내를 다듬고, 반복되는 설명과 어려운 표현을 줄였습니다.
- 문의와 버그 제보는 텔레그램으로 안내합니다.
- GitHub의 사용자 여정 테스트 실패 내용을 문서에 남겼습니다.
- 앱 기능과 버전, 이미 공개된 태그의 소스는 변경하지 않았습니다.

## v0.2.0-alpha.1 — 첫 공개 테스트 버전

- 폴더 트리·큰 폴더·큰 파일을 같은 분석 결과에서 탐색합니다.
- 파일 종류·최소 크기·이름으로 검색하고 폴더 내부로 좁힐 수 있습니다.
- 정리 후보에 근거와 확인할 점을 표시하고 Finder로 연결합니다.
- 앱의 크기·마지막 사용 기록을 참고하고 보관할 앱을 표시합니다.
- 앱 본체 하나만 별도 확인 후 휴지통으로 이동합니다. 관련 Library 파일은 조회만 합니다.
- 직접 빌드·설치·이전 버전 복구 스크립트를 제공합니다.

앱 내부 버전은 0.2.0 (2)입니다. 검증 범위와 남은 과제는 [테스트 안내](TESTING.md)를 참고하세요.
